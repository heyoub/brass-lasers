VS Code

code --install-extension heyoub.brass-lasers-4am

      
Cursor · VSCodium
From Open VSX: search Brass Lasers 4AM in Extensions.
heyoub.brass-lasers-4am

      
Neovim
The repo is a lazy.nvim plugin.
{ "heyoub/brass-lasers", lazy = false, priority = 1000,
  config = function() vim.cmd.colorscheme("brass-lasers-atrium") end }
