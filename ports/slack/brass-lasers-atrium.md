# Brass Lasers Atrium 5AM for Slack

Slack → **Preferences → Appearance → Themes → Create a custom theme**, then enter:

| Field | Color |
|---|---|
| Window background | `#121717` |
| System navigation | `#101413` |
| Selected items | `#79c9c3` |
| Presence indication | `#a6c6a0` |
| Notifications | `#e7ad70` |

Set **Mode** to **dark**.
