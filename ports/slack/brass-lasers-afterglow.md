# Brass Lasers Afterglow for Slack

Slack → **Preferences → Appearance → Themes → Create a custom theme**, then enter:

| Field | Color |
|---|---|
| Window background | `#171114` |
| System navigation | `#130e10` |
| Selected items | `#ff7a6b` |
| Presence indication | `#ffd6a5` |
| Notifications | `#f29bb2` |

Set **Mode** to **dark**.
