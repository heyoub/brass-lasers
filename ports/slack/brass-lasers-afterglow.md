# Brass Lasers Afterglow for Slack

Slack → **Preferences → Appearance → Themes → Create a custom theme**, then enter:

| Field | Color |
|---|---|
| Window background | `#0f0d15` |
| System navigation | `#0c0a10` |
| Selected items | `#e476a1` |
| Presence indication | `#beea92` |
| Notifications | `#e5ba78` |

Set **Mode** to **dark**.
