# Brass Lasers 4AM for Slack

Slack → **Preferences → Appearance → Themes → Create a custom theme**, then enter:

| Field | Color |
|---|---|
| Window background | `#0a0711` |
| System navigation | `#07050c` |
| Selected items | `#ff3d9a` |
| Presence indication | `#b6ff5c` |
| Notifications | `#ffb627` |

Set **Mode** to **dark**.
