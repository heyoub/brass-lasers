# Brass Lasers Daybreak for Slack

Slack → **Preferences → Appearance → Themes → Create a custom theme**, then enter:

| Field | Color |
|---|---|
| Window background | `#f0f1f4` |
| System navigation | `#ebecef` |
| Selected items | `#be3278` |
| Presence indication | `#262a4a` |
| Notifications | `#8a5a00` |

Set **Mode** to **light**.
