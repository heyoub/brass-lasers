# Brass Lasers Liquid Metal for Slack

Slack → **Preferences → Appearance → Themes → Create a custom theme**, then enter:

| Field | Color |
|---|---|
| Window background | `#0a0a0b` |
| System navigation | `#0a0a0b` |
| Selected items | `#a78bfa` |
| Presence indication | `#22d3ee` |
| Notifications | `#eab308` |

Set **Mode** to **dark**.
