# Brass Lasers Soundcheck for Slack

Slack → **Preferences → Appearance → Themes → Create a custom theme**, then enter:

| Field | Color |
|---|---|
| Window background | `#111113` |
| System navigation | `#0a0a0b` |
| Selected items | `#e580b3` |
| Presence indication | `#55bf70` |
| Notifications | `#f0c25f` |

Set **Mode** to **dark**.
