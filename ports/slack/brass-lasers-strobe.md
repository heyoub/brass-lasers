# Brass Lasers Strobe for Slack

Slack → **Preferences → Appearance → Themes → Create a custom theme**, then enter:

| Field | Color |
|---|---|
| Window background | `#030106` |
| System navigation | `#020104` |
| Selected items | `#fe7aaf` |
| Presence indication | `#c0ff7b` |
| Notifications | `#ffd595` |

Set **Mode** to **dark**.
