# Brass Lasers Strobe for Slack

Slack → **Preferences → Appearance → Themes → Create a custom theme**, then enter:

| Field | Color |
|---|---|
| Window background | `#030304` |
| System navigation | `#020202` |
| Selected items | `#ff5fdc` |
| Presence indication | `#86ff6a` |
| Notifications | `#ffe24d` |

Set **Mode** to **dark**.
