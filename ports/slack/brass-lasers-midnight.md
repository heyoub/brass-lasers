# Brass Lasers Midnight for Slack

Slack → **Preferences → Appearance → Themes → Create a custom theme**, then enter:

| Field | Color |
|---|---|
| Window background | `#0c111d` |
| System navigation | `#0a0e18` |
| Selected items | `#ff9f43` |
| Presence indication | `#c9e2ff` |
| Notifications | `#f5d76e` |

Set **Mode** to **dark**.
