# Brass Lasers Golden Hour for Slack

Slack → **Preferences → Appearance → Themes → Create a custom theme**, then enter:

| Field | Color |
|---|---|
| Window background | `#f4efdd` |
| System navigation | `#efeadc` |
| Selected items | `#c02e6d` |
| Presence indication | `#1f3a3d` |
| Notifications | `#9d5901` |

Set **Mode** to **light**.
