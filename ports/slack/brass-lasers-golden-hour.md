# Brass Lasers Golden Hour for Slack

Slack → **Preferences → Appearance → Themes → Create a custom theme**, then enter:

| Field | Color |
|---|---|
| Window background | `#fcf2e4` |
| System navigation | `#f6edde` |
| Selected items | `#b20965` |
| Presence indication | `#487102` |
| Notifications | `#835a03` |

Set **Mode** to **light**.
