# Brass Lasers Liquid Metal for Raycast

Open this link on a Mac with Raycast installed. It adds the theme to Raycast's theme studio:

```
raycast://theme?version=1&name=Brass%20Lasers%20Liquid Metal&appearance=dark&colors=%23111113,%230a0a0b,%232c2c31,%23f4f4f5,%23544a75,%23a78bfa,%23ef4444,%23ff6b6b,%23eab308,%2322d3ee,%2322d3ee,%238c5ef8,%23c4b5fd
```

Colors in order: background, secondary background, border, text, selection, loader, red, orange, yellow, green, blue, purple, magenta.
