# Brass Lasers Atrium 5AM for Raycast

Open this link on a Mac with Raycast installed. It adds the theme to Raycast's theme studio:

```
raycast://theme?version=1&name=Brass%20Lasers%20Atrium 5AM&appearance=dark&colors=%23151c1b,%23121717,%23293331,%23e9e4d6,%23226a66,%2379c9c3,%23e07b7b,%23e3977a,%23e7ad70,%23a6c6a0,%23c4a2d8,%239db8d6,%23dba9b3
```

Colors in order: background, secondary background, border, text, selection, loader, red, orange, yellow, green, blue, purple, magenta.
