# Brass Lasers Daybreak for Raycast

Open this link on a Mac with Raycast installed. It adds the theme to Raycast's theme studio:

```
raycast://theme?version=1&name=Brass%20Lasers%20Daybreak&appearance=light&colors=%23f5f6fb,%23f0f1f4,%23d1d3de,%23262a4a,%23c9d3fe,%23be3278,%23c62828,%23c2410c,%238a5a00,%23262a4a,%232563a8,%235b4fc4,%23b0306b
```

Colors in order: background, secondary background, border, text, selection, loader, red, orange, yellow, green, blue, purple, magenta.
