# Brass Lasers 4AM for Raycast

Open this link on a Mac with Raycast installed. It adds the theme to Raycast's theme studio:

```
raycast://theme?version=1&name=Brass%20Lasers%204AM&appearance=dark&colors=%230e0a17,%230a0711,%232a1f47,%23efe6d5,%233a1640,%23ff3d9a,%23ff4d6d,%23ff8a3d,%23ffb627,%23b6ff5c,%233df2e0,%23b18cff,%23ff7fc0
```

Colors in order: background, secondary background, border, text, selection, loader, red, orange, yellow, green, blue, purple, magenta.
