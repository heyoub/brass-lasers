# Brass Lasers Golden Hour for Raycast

Open this link on a Mac with Raycast installed. It adds the theme to Raycast's theme studio:

```
raycast://theme?version=1&name=Brass%20Lasers%20Golden%20Hour&appearance=light&author=heyoub&authorUsername=heyoub&colors=%23fcf4dc,%23f4efdd,%231f3a3d,%23a6e1da,%23c02e6d,%23c9262c,%23ba4c0d,%239d5901,%231f3a3d,%232867b2,%236455b8,%23b8385f
```

Colors in Raycast's order (the same order [ray.so/themes](https://ray.so/themes) uses): background, secondary background, text, selection, loader, red, orange, yellow, green, blue, purple, magenta.
