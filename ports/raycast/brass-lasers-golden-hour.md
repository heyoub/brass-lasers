# Brass Lasers Golden Hour for Raycast

Open this link on a Mac with Raycast installed. It adds the theme to Raycast's theme studio:

```
raycast://theme?version=1&name=Brass%20Lasers%20Golden Hour&appearance=light&colors=%23fef9f1,%23fcf2e4,%23d2cdea,%23231d11,%23e8cdec,%23b20965,%23b9003d,%239b4801,%23835a03,%23487102,%2301736a,%236f47b4,%23b73d81
```

Colors in order: background, secondary background, border, text, selection, loader, red, orange, yellow, green, blue, purple, magenta.
