# Brass Lasers Afterglow for Raycast

Open this link on a Mac with Raycast installed. It adds the theme to Raycast's theme studio:

```
raycast://theme?version=1&name=Brass%20Lasers%20Afterglow&appearance=dark&colors=%231d1418,%23171114,%23432b36,%23f4e4d6,%237c4a43,%23ff7a6b,%23ff5f6d,%23ffb07a,%23f29bb2,%23ffd6a5,%238fb8ff,%23c3a6ff,%23ff9e8f
```

Colors in order: background, secondary background, border, text, selection, loader, red, orange, yellow, green, blue, purple, magenta.
