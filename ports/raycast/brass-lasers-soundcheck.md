# Brass Lasers Soundcheck for Raycast

Open this link on a Mac with Raycast installed. It adds the theme to Raycast's theme studio:

```
raycast://theme?version=1&name=Brass%20Lasers%20Soundcheck&appearance=dark&colors=%2318181b,%23111113,%2334343c,%23e4e4e7,%2332636c,%23e580b3,%23e77f7c,%23ec9a5e,%23f0c25f,%2355bf70,%2360cfe3,%23a591e7,%23efafd1
```

Colors in order: background, secondary background, border, text, selection, loader, red, orange, yellow, green, blue, purple, magenta.
