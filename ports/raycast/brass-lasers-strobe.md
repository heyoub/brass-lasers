# Brass Lasers Strobe for Raycast

Open this link on a Mac with Raycast installed. It adds the theme to Raycast's theme studio:

```
raycast://theme?version=1&name=Brass%20Lasers%20Strobe&appearance=dark&colors=%23050507,%23030304,%231d1d24,%23ffffff,%2359324e,%23ff5fdc,%23fe6679,%23ffa24d,%23ffe24d,%2386ff6a,%232ee8ff,%23c2a8ff,%23ff8de2
```

Colors in order: background, secondary background, border, text, selection, loader, red, orange, yellow, green, blue, purple, magenta.
