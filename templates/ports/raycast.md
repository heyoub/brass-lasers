# Brass Lasers {{meta.name}} for Raycast

Open this link on a Mac with Raycast installed. It adds the theme to Raycast's theme studio:

```
raycast://theme?version=1&name={{meta.nameUrl}}&appearance={{meta.appearance}}&author=heyoub&authorUsername=heyoub&colors=%23{{base|nohash}},%23{{mantle|nohash}},%23{{text|nohash}},%23{{selectionActive|nohash}},%23{{pink|nohash}},%23{{red|nohash}},%23{{sunset|nohash}},%23{{brass|nohash}},%23{{lime|nohash}},%23{{blue|nohash}},%23{{uv|nohash}},%23{{pinkLight|nohash}}
```

Colors in Raycast's order (the same order [ray.so/themes](https://ray.so/themes) uses): background, secondary background, text, selection, loader, red, orange, yellow, green, blue, purple, magenta.
